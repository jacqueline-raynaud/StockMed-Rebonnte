## Comment insérer une capture

!!! tip "À supprimer une fois la page remplie"

    Les images vont dans `docs/assets/profiler/`. La syntaxe de base :
    ```markdown
    <figure markdown>
      ![Tas description image pour lecteur ecran](assets/profiler/image.png){ width="700" }
      <figcaption>Légende en dessous de l'image</figcaption>
    </figure>
    ```
